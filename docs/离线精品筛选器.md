# 离线精品筛选器

只显示两列：**地址、位数**。位数是匹配结构的有效长度，不是地址总长度。
处理完成后直接打开 `总排行榜.txt`，不需要看密集的 CSV 原始文本。
每个系列的排行榜在 `分类` 文件夹，也同时提供两列 TXT 和 CSV。

## 新排序规则

评分版本 3 取消原来的五项加权，改为严格的优先顺序：

1. **长度优先**：有效结构越长越靠前。长一位始终优先于短一位。
2. **同长度比较首尾距离**：匹配片段距离开头或结尾越近，越靠前。
3. 长度与距离都相同，按地址稳定排序。

首尾同等优先。紧跟固定 `T` 的第一个字符算开头，距离为 0；片段从 `T` 开始也算 0。
尾部距离是片段结束后剩余的字符数。排序使用两端距离中较小的一个。
例如同为 10 位：贴头/贴尾优先，其次距离任一端 1 位、2 位，依此类推。
11 位的中间结构仍然排在 10 位的尾部结构前面。

不再按大小写、视觉、结构整齐程度或个人偏好加减分。同一个片段提供长度和距离，
不能混用不同片段的优势。各系列取该地址最长、最靠近首尾的片段，总榜取其最佳片段。
只接受已经识别的结构，不把旁边随机字符凑进长度；若相邻字符本身也是合法结构的一部分，
则会计入，例如 `aabbccddeeffRR` 是 14 位成对分组。

后台保留单调对应这个顺序的排序分：`100 × (长度×100 + 34 - 最近距离) / 3434`。
它只用于机器数据和可选最低分过滤，不在排行榜展示，不表示稀有度或价格。
原来的五项评分配置不再支持，传入旧配置会明确提示，不会悄悄套用旧权重。

## 使用

仅需 Python 3.9 或更新版本，无需显卡、CUDA 或第三方库。

Windows：解压独立包，双击 `靓号筛选器.bat`，输入或拖入结果文件路径后回车。
也可以把结果文件直接拖到 BAT 上；BAT 和 `vanity_ranker.py` 放在同一目录。

```bash
# 处理生成器的结果目录
python vanity_ranker.py "命中地址"

# 指定一个文件和新的输出目录
python vanity_ranker.py "命中地址/matches_时间.jsonl" -o "本次精品结果"

# 多批数据合并去重
python vanity_ranker.py "第一批.jsonl" "第二批.txt" "第三批.csv"

# 至少10位，每张榜只输出前100个
python vanity_ranker.py "命中地址" --min-length 10 --top 100
```

默认重新检查 8～34 位结构。`--min-length`、`--max-length` 可以修改范围；
`--top 0` 表示全部。默认输出到 `精选结果/时间/`，已有非空目录不会覆盖。
生成器仍在写文件时，最后一条不完整 JSON 会列为导入问题，正常退出后可重新导入原文件。
无需停止正在工作的 GPU 来使用本程序，也不会修改输入文件。

## 文件布局

```text
精选结果/时间/
    总排行榜.txt          直接打开看，只含地址和位数
    总排行榜.csv          同样两列，供Excel使用
    未匹配.txt / .csv      无符合长度范围的结构，位数记为0
    分类/
        纯豹子.txt / .csv
        成对分组.txt / .csv
        纯数字回文.txt / .csv
        ...
    详细数据/
        完整评分结果.jsonl
        评分索引.sqlite3
        评分配置.json
        统计.json
        导入问题.csv
```

TXT 用空格分开两列，CSV 使用 UTF-8 BOM，便于 Excel 显示中文。
排行榜不显示评分、标签、位置、记录ID或私钥。私钥、匹配详情及原始来源信息只保留在
`详细数据` 中，可以按地址查找。取消原来的 `--include-private-keys` 参数。
`--top` 和 `--min-score` 只影响排行榜；完整 JSONL 始终保留全部有效输入地址。

## 导入和系列

优先给程序生成器产生的 `matches_日期_时间.jsonl`，不要选 `.stats.json` 或 `.index.sqlite3`。
也支持 TXT（每行地址，私钥在同一行或下一行）及 CSV。
CSV 地址列支持 `address`、`地址`、`钱包地址`、`TRON地址`；私钥列支持 `private_key`、`privkey`、`私钥`。
支持 UTF-8、带 BOM 的 UTF-16 和 GB18030。旧版完整 CSV 可重新导入，用新规则排序。
目录导入不递归子目录。同一地址自动去重，多个来源的元数据保留。

系列包括纯豹子、同字母混合大小写、成对分组、等长多连分组、阶梯分组、对称分组、
变长分组、顺序分组、数字顺子、数字循环顺子、数字周期重复、含字母周期重复、
纯数字回文、含字母回文、连续纯数字。一个地址可进多个系列，但在每张榜只出现一次。

导入检查 TRON Base58Check 校验和、私钥格式及标量范围，不进行私钥对应地址的椭圆曲线验证。
生成器的原验证信息保留在元数据中。只有地址也能排名。私钥冲突不覆盖，完整 JSONL 保留所有冲突值。
内存采用逐行读取、SQLite 排序；数据较大时会显示进度。
退出码：0 成功，2 完成但有导入问题或私钥冲突，1 执行失败，130 用户中止。
