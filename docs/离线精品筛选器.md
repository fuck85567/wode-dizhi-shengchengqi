# 离线靓号精品筛选器

`vanity_ranker.py` 是独立程序，仅需要 Python 3.9 或更新版本。
不导入 GPU 生成器、不需要 CUDA、不需要安装第三方库；可以复制到另一台电脑单独使用。
它读取已有地址，重新检查完整 34 位地址，再按系列评分排序。默认最少 8 位。

## 使用

Windows 可以双击 `靓号筛选器.bat`，输入或拖入结果文件路径。
也可以把结果文件直接拖到 BAT 上。BAT、Python 脚本需放在同一个目录。

命令行：

```bash
# 处理生成器输出的整个目录（不递归子目录）
python vanity_ranker.py "命中地址"

# 单个文件；输出目录必须是新目录或空目录
python vanity_ranker.py "命中地址/matches_时间.jsonl" -o "本次精品结果"

# 多个文件自动合并、按地址去重
python vanity_ranker.py "第一批.jsonl" "第二批.txt" "第三批.csv"

# 每张排行榜最多 100 条，且至少 80 分
python vanity_ranker.py "命中地址" --top 100 --min-score 80

# 修改权重或偏好后重排，不必重新搜索地址
python vanity_ranker.py "命中地址" --config ranker_config.example.json
```

无参数运行会提示输入文件或目录。默认输出到当前目录的 `精选结果/时间/`。
生成器可以继续运行；处理正在写入的文件时，最后一条未写完的 JSON 会记录为导入问题，
之后重新处理该文件即可。要获得完整的一批结果，可等生成器正常退出后再导入。

## 输入格式

- **JSONL（优先使用）**：直接读取生成器的输出。每行一个 JSON 对象，至少有 `address`。
  可含 `private_key`、时间、原分类、原匹配等；原始元信息保留在 `sources[].metadata`。
  不使用原来的最长匹配代替重新评分，因此调整偏好后可以重新选择更合适的片段。
- **CSV**：UTF-8/UTF-8 BOM、UTF-16 BOM 或 GB18030。地址列名为 `address`、`地址`、`钱包地址`、`TRON地址` 之一；
  私钥列名为 `private_key`、`privkey`、`私钥` 之一。其他列作为原始元信息保留。
- **TXT**：每行一个地址；可在同一行附上 64 位十六进制私钥，或在紧随地址的下一行写 `私钥：…`。
  也支持内容实际为 JSONL 的 `.txt`。普通 TXT 提取地址/私钥，其他描述行不参与评分；原文件不会修改。
  不支持把不同地址、不同私钥各列成一批再自动猜测对应关系。

导入时检查 TRON Base58Check 校验和、私钥格式及标量范围。
**本程序不重新进行椭圆曲线计算，不把格式检查标记成私钥与地址对应验证。**
GPU 生成器已有的验证信息按原始元数据保留。只有地址、没有私钥也能正常排名。

## 五项评分

默认 `35 + 25 + 25 + 10 + 5 = 100`，可用 JSON 配置修改。分数均来自同一个匹配片段。

| 项目 | 上限 | 规则 |
| --- | ---: | --- |
| 有意义长度 | 35 | `权重 × log(有效长度) / log(系列最大长度)`；数字顺子上限 9，其他系列上限 34。长度越长分数越高，增长逐渐放缓。不把随机字符算入长度。 |
| 视觉一致性 | 25 | 统一大小写/纯数字系数 1；大小写交替 0.95；大小写周期 0.90；大小写对称 0.88；较杂时按各连续组的大小写统一程度取 0.45～0.70。数字字母混排再乘 0.90。 |
| 结构规整 | 25 | 豹子、同字母、数字顺子、回文系数 1。等长分组 0.94，字符递增/递减加 0.06；阶梯分组 0.95，字符有序加 0.05；组长对称 0.92，字符有序加 0.05。变长分组按组长一致率、单调变化、字符顺序计分，上限 0.92。 |
| 位置 | 10 | 默认尾部系数 1，开头系数 0.8，中间系数 0.5；开头指匹配从第 0 位或紧跟固定 `T` 的第 1 位开始。一个片段同时覆盖首尾时按尾部计分。 |
| 个人偏好 | 5 | 默认未设置，统一 0 分。偏好字符按片段内的占比计分，字母忽略大小写；偏好系列命中得满系数。两项同时设置时各占一半。 |

周期结构系数为 `0.80 + 完整周期加0.12 + 0.08×(2/周期长度)`，支持周期 2～4。
例如完整 `ABABABAB` 的结构系数为 1；完整 `ABCABCABC` 约 0.973；未完整收尾会扣分。

变长分组系数为 `min(0.92, 0.55 + 0.25×最常见组长占比 + 单调组长加0.10 + 字符有序加0.10)`。
阶梯至少有 3 组且组长逐组加 1 或减 1；对称组长至少有 3 组、不是全等长，且组长序列左右一致。
分组必须满足每组至少 2 位，或者组字符连续递增/递减（这时允许单字符组）。

未设置个人偏好时，总分最高为 95。排行榜按总分降序，同分按有效长度降序，再按地址稳定排序。
**分数是审美排序，不是命中概率、稀有度或价格。不同系列优先看各自榜单，总榜仅供参考。**

视觉评分和结构评分分别计算。例如 `AAccBBDd` 的分组仍然有效，视觉分低于 `aaccbbdd`；
`abbcccdddd` 是规律阶梯，不会因为组长不同就按杂乱分组处理。

## 系列与去重

包含纯豹子、同字母混合大小写、成对分组、等长多连分组、阶梯分组、对称分组、
变长分组、顺序分组、数字顺子、周期重复、回文对称。

- 地址在总表只出现一次，每个系列表也至多出现一次。
- 一个地址可以出现在多个不同系列；每个系列选择该地址评分最高的片段。
- 不只检查最长片段：较短但大小写更整齐、周期更完整或位置更好的片段，可能得分更高。
- `AAAAaaaa` 折叠后仍然只有一组，不会被拆成两组；纯同字符归纯豹子，混合大小写归同字母系列。
- 同一地址来自多个文件时，所有来源和原始元信息保留。
- 同一地址出现不同私钥时，不覆盖旧私钥；标记冲突并在完整 JSONL 中保留不同值，CSV 私钥留空。

## 输出文件

| 文件 | 内容 |
| --- | --- |
| `总排行榜.csv` | 每个地址的最佳片段，按分数降序 |
| 各系列 `.csv` | 该系列内每个地址的最高分片段，按分数降序 |
| `未匹配.csv` | 没有符合所选长度范围的结构的有效地址 |
| `完整评分结果.jsonl` | 全部有效地址、每个系列的最佳评分、私钥和原始元数据，不受最低分/前 N 名限制 |
| `导入问题.csv` | 无效地址、格式错误等问题及来源行号，不输出原始私钥文本 |
| `评分配置.json` / `统计.json` | 本次实际配置及输入数量、去重数、各系列数量等 |
| `评分索引.sqlite3` | 本次排序和去重用的工作数据库，包含地址、私钥和来源元数据 |

CSV 使用 UTF-8 BOM，便于 Excel 显示中文。默认 CSV 不重复写私钥，通过 `记录ID` 对应完整 JSONL。
需要 CSV 也带私钥时使用 `--include-private-keys`；私钥应按文本导入，避免表格软件转换数字。
`开始位置` 从 0 计数。各项分数、匹配内容、组数、组长度、结构标签和评分说明均单独列出。

采用逐行读取和 SQLite 排序，不把所有输入文件一次装进内存。无需显卡，数据较大时会定期显示进度。
源文件始终不修改，已有非空输出目录不会被覆盖。程序退出码：0 成功，2 完成但有导入问题/私钥冲突，
1 执行失败，130 用户中止。中止或失败的输出可能不完整，重新指定新目录处理原文件即可。

## 验证

独立测试 11 项通过，覆盖评分、系列、位置、字符大小写、文件导入、校验和、去重、排序、
前 N 名/最低分导出、私钥冲突及原始元数据保留。禁用第三方包的实际命令行运行通过。
与生成器分类器进行了 2,457 组规则覆盖对照，是否命中一致；评分时允许选取更优的较短片段。

```bash
# -S 禁用第三方包加载，验证该工具可以独立运行
python -S -m unittest test_ranker
```
